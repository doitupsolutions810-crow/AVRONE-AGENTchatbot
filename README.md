# Wired Agents Harness

Prototype UI for a persistent, long-lived agent system modeled after Grok Bots.

## Features demonstrated
- Bot roster (sidebar) with avatars, status, last activity
- Persistent chat per agent
- Shared computer status / preview / takeover controls
- Dark lattice aesthetic matching CycleKernel / AVRONE surfaces

## Next steps
- Wire real LLM backend (Avrone daemon / CycleKernel)
- Persist memory & routines
- Integrate computer-use preview (shared VM)
